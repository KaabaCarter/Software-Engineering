# Design files

Source of the Claude Design canvas **"Wizard Duel — Visual Direction"**:
https://claude.ai/artifact/WYyZxLGZbxtK4psYhLgyRG

These `.dc.html` files are Claude Design boards (reference only — they render
inside Claude Design, not as standalone web pages). The canvas link above is
the live version; re-export if it changes.

| Board | What it shows |
|---|---|
| `Main`, `Controls`, `Select`, `Arena`, `Hud`, `Pause`, `RoundOver`, `MatchOver` | The 8 game screens at 960 × 540 |
| `StyleGuide` | Palette, typography, UI components |
| `CharacterSheet`, `SageSheet`, `NewWizards` | Ember, Sage, and future Quill / Bramble |
| `Spells`, `Fx` | Spell and effect concept frames |
| `Wizard`, `Hall` | Reusable wizard sprite and castle background |
| `Pitch1`–`Pitch7` | 7-slide pitch deck |
| `canvas.json` | Canvas layout index |
